Fill in the cPanel "Setup Node.js App" form with these values:

| Field | Value |

## 🔧 Deployment Steps

### Option 1: Local Build & Upload (Recommended)

#### 1. Build Locally
```bash
cd /home/frobenius/Desktop/Femtech/HR/Frontend

# Install dependencies
npm install

# Build for production
npm run build

# This creates the 'build' folder with optimized assets
```

#### 2. Upload to cPanel
Upload these files/folders to `app.tripa.com.ng`:
- ✅ `server.js`
- ✅ `package.json`
- ✅ `.env.production`
- ✅ `build/` (entire folder)

#### 3. Install Dependencies on Server
In cPanel Terminal or SSH:
```bash
cd /home/[username]/app.tripa.com.ng
npm install --production
```

#### 4. Configure Environment
Create `.env` file in `app.tripa.com.ng`:
```bash
NODE_ENV=production
VITE_API_URL=https://hrapi.tripa.com.ng
```

#### 5. Start Application
In cPanel Node.js App interface:
1. Click **Restart** button
2. Check logs for "Femtech HR App is running on port XXXX"

## 🔐 Environment Variables

### Production `.env` file:
```env
NODE_ENV=production
VITE_API_URL=https://hrapi.tripa.com.ng
```

### What each variable does:
- `NODE_ENV`: Sets React to production mode (optimizations enabled)
- `VITE_API_URL`: Base URL for all API requests

## 🐛 Troubleshooting

### Application won't start
```bash
# Check logs in cPanel or run:
cd /home/[username]/app.tripa.com.ng
cat logs/error.log

# Verify Node.js version:
node --version  # Should be v20.x
```

### 404 on refresh
Ensure `server.js` is correctly serving `index.html` for all routes.

### API calls failing
1. Check `.env` has correct `VITE_API_URL`
2. Verify CORS is enabled on backend
3. Check browser console for exact error

### Build errors
```bash
# Clear cache and rebuild
rm -rf node_modules build package-lock.json
npm install
npm run build
```

## 🔒 Security Notes

1. **Never commit `.env`** - Add to `.gitignore`
2. **Use HTTPS** - Ensure SSL certificate is installed
3. **CORS Configuration** - Backend should only allow `https://app.tripa.com.ng`
4. **Environment Variables** - Store secrets in cPanel environment, not code
